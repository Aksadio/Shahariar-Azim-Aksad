# Aksad — Portfolio

Personal portfolio website of Shahariar Azim Aksad — a self-taught developer and AI automation builder based in Bangladesh, working across Python, n8n, and AI tools.

## Live Site

[aksadio.github.io/my-portfolio](https://aksadio.github.io/my-portfolio/)

## Tech Stack

- **Framework**: Next.js 14 (static export)
- **3D Graphics**: React Three Fiber, React Three Drei
- **Animations**: GSAP, Framer Motion, React Spring
- **Styling**: Tailwind CSS
- **Utilities**: Lenis (smooth scrolling), Parallax.js

## Development

```bash
npm install
npm run dev
```

Deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.
